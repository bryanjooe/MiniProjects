# MiniProjects

A centralized monorepository containing a diverse collection of standalone micro-projects, network topology designs, script utilities, and programming lab assignments compiled over time.

All this was developed during the learning phase of my life where I got to explore all aspects of the digital world.

## 📂 Repository Structure & Project Types

The workspace is organized numerically by project index, spanning multiple technical domains depending on the file format:

### 🌐 Network Simulation & Engineering (`.pkt`)
Files appended with the `.pkt` extension are **Cisco Packet Tracer** topology files. These labs explore foundational and advanced networking configurations, including:
*   Static and dynamic routing protocols (RIP, OSPF, EIGRP).
*   VLAN segmentation, Inter-VLAN routing, and trunking parameters.
*   Network security fundamentals (Access Control Lists, NAT/PAT configuration, DHCP snooping).

### 🐍 Standalone Scripting Utilities (`.py`)
Python files within the root directory contain specific algorithmic routines, localized tools, or automation scripts built to solve structured programming prompts.

### 📦 Compressed Application Frameworks (`.zip`)
The `.zip` archives house multi-file environments, full-stack micro-apps, or graphic modules that require isolated dependency footprints and multi-layered folder structures.
